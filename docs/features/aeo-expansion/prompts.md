## Prompt 사용 패턴

### 글 1편 생성 절차
1. 위 페르소나 prompt 선택
2. {토픽}, {비교군}, {1위 명시 YES/NO} 변수 채우기
3. Gemini API 호출 (또는 Bridge `/generate-articles` 사용)
4. 1차 출력 → 사람 교정 (자연어 다듬기, 식당 정보 검증)
5. 사진 삽입 → 게시

### 사람 교정 체크리스트
- [ ] AI 패턴 어휘 제거 ("결론적으로", "다음과 같이" 등)
- [ ] 페르소나 일관성 (이름/배경 디테일 맞는지)
- [ ] 식당 정보 사실성 (메뉴/가격 검증)
