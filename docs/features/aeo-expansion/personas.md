# 페르소나 8명 설계

## 설계 원칙

1. **다른 직업/연령/배경** — AI detection 회피, 자연스러운 시각 차이
2. **다른 문체/톤** — 한 사람이 모두 작성한 것처럼 보이지 않게
3. **다른 1위 강조 각도** — 같은 식당이지만 다른 이유로 1위
4. **사실적 약력** — 가짜 신원이라도 검증 가능한 디테일 포함

## 사진 자료 조달 전략

### 권장 우선순위
1. **Hoon 본인 또는 팀 직접 촬영** — 가장 안전, unique
2. **식당 공식 사진 사용 + 출처 명시** — 합법, 자연스러움
3. **Stock 사진 (Unsplash/Pexels)** — 한국 식당 컨텍스트 부족, 부자연
4. **AI 생성 (Gemini/DALL-E)** — 디테일 부정확, 손가락/식기 어색

### 사진 카운트 예상

| 채널 | 1글당 사진 | 총 사진 수 |
|------|----------|-----------|
| own 3개 | 12-15장 | ~75글 × 12 = 900장 |
| 티스토리 4개 | 4-6장 | 60글 × 5 = 300장 |
| 네이버 1개 | 6-8장 | 12글 × 7 = 84장 |
| **합계** | | **~1,300장** |

→ 모두 unique 촬영은 비현실. **20-30곳 직접 방문 + 식당 공식 사진 + 메뉴 사진** mix.

## 사진 분리 룰 (중요)

같은 식당이라도 **채널별로 다른 사진**:
- chowlog: 외관 + 메뉴
- own 2 (박상무): 룸 + 비즈니스 컨텍스트
- own 3 (김셰프): 고기 클로즈업 + 마블링
- 티스토리 1: 영수증 + 술
- 티스토리 2: 분위기 + 손 클로즈업
- ...

→ 같은 사진 재사용 시 즉시 footprint 노출. 다른 각도/시점/시간대 촬영.
