# 가입/세팅 체크리스트

## 0. IP 분리 전략 (모든 다중 계정의 핵심)

### 필요 IP 4종류

| 용도 | 어디서 | 비고 |
|------|-------|------|
| Hoon 본인 IP | 자택 | 본인 1 계정용 |
| 가족 1 IP | 부모/배우자 자택 | 1 계정용 |
| 가족 2 IP | 형제 자택 | 1 계정용 |
| 친구/카페 IP | 카페 wifi 또는 친구 자택 | 1 계정용 |

OR **VPN 4국가**:
- ProtonVPN (한국 연결 시 다양한 출구 IP)
- Mullvad (5 동시 연결, $5/월)
- 단점: 같은 VPN 서비스 IP는 spam DB에 등재된 경우 多 → 가입 거부 가능

→ **실제 다른 IP가 가장 안전**. VPN은 차선.

### 절대 하지 말 것
- 같은 wifi에서 여러 카카오/네이버 가입 (즉시 sock puppet 감지)
- 모바일 핫스팟으로 핸드폰 IP 우회 (같은 통신사 IP 풀)
- 카카오 가입 후 30분 내 다른 카카오 가입 (시간 패턴 감지)

## 1. own 도메인 구매 (Hoon)

### Porkbun 기준 단계

1. https://porkbun.com 가입 (Gmail 또는 별도 메일)
2. 검색 → 추천 도메인 (`docs/features/aeo-expansion/domain-candidates.md` 참조)

- [ ] 도메인 2 구매 (예: hanwoo-master.com)
- [ ] WHOIS Privacy 적용 확인
- [ ] Auto-renew 적용 확인
- [ ] 등록 완료 메일 보관

## 2. 카카오 계정 4개 준비 (티스토리용)

### 명의 결정

| 계정 | 명의자 | IP 출처 | 가입 시점 분산 |
|------|-------|--------|--------------|
| 티스토리 1 | Hoon | 자택 | Day 1 |
| 티스토리 2 | 가족 1 (배우자/부모) | 가족 1 자택 | Day 2 |
| 티스토리 3 | 가족 2 (형제) | 가족 2 자택 | Day 4 |
| 티스토리 4 | 친구 (동의 받은 사람) | 친구 자택 또는 카페 | Day 6 |

### 카카오 가입 절차 (1 계정당)

1. https://accounts.kakao.com 가입
2. 본인인증 (휴대폰 SMS) — **명의자 본인 명의 핸드폰 필수**
3. 프로필 사진/이름 설정 (페르소나에 맞게)
4. 가입 후 24시간 대기 (계정 안정화)

### 체크리스트
- [ ] 가족 1 동의 + 휴대폰 차용 약속
- [ ] 가족 2 동의 + 휴대폰 차용 약속
- [ ] 친구 동의 + 휴대폰 차용 약속
- [ ] 카카오 계정 1 (Hoon) 생성
- [ ] 카카오 계정 2 (가족 1) 생성 — 다른 IP, Day 2+
- [ ] 카카오 계정 3 (가족 2) 생성 — 다른 IP, Day 4+
- [ ] 카카오 계정 4 (친구) 생성 — 다른 IP, Day 6+

### ⚠️ 주의

- **본인 명의 휴대폰 필수**: 본인인증 통과 못하면 계정 정지
- **30일 이상 사용 후 글 게시 권장**: 신규 계정 즉시 게시 = sock puppet 의심
  → Hoon 일정상 30일 못 기다리면 **최소 1주는 활동 (다른 사람 글 좋아요/댓글) 후 게시**

## 3. 티스토리 4 블로그 개설

### 1 블로그당 절차

1. 카카오 계정으로 https://www.tistory.com 로그인
2. 블로그 개설 → URL 결정 (`{username}.tistory.com`)
3. 스킨 선택 (페르소나 컨셉에 맞게)
4. 카테고리 설정:
   - 강남 외식 / 회식 / 가족 모임 / 데이트 (페르소나 1)
   - 데이트 / 기념일 / 와인 / 분위기 (페르소나 2)
   - 프라이빗룸 / 접대 / VIP / 호텔식 (페르소나 3)
   - BEST / 비교 / 추천 / 가격대별 (페르소나 4)
5. 프로필 사진/소개 입력 (페르소나 약력 활용)
6. 첫 글: 가벼운 자기소개 (식당 글 X)
7. **1주일 활동**: 다른 블로그 댓글 + 좋아요

### 체크리스트
- [ ] 티스토리 1 (정민호) 개설 — URL 결정 후 작성
- [ ] 티스토리 2 (이지영 부부) 개설
- [ ] 티스토리 3 (최실장) 개설
- [ ] 티스토리 4 (강남위클리) 개설
- [ ] 4 블로그 모두 자기소개 글 1개씩 게시
- [ ] 1주 활동 (댓글/좋아요)

1. 네이버 계정 생성 (또는 기존 Hoon 계정 활용)

5. 첫 글: 자기소개

### 체크리스트

- [ ] 블로그 개설
- [ ] 카테고리 설정
- [ ] 자기소개 글
- [ ] 이웃 5-10명 (다른 미식 블로그) 추가 — 자연스러운 활동 신호

### 다중 계정 시 (비추)
네이버 본인인증 매우 엄격. 가족/친구 명의로 계정 1개 더 만들 수도 있지만:
- 같은 IP 가입 시 즉시 정지
- 본인인증 통과 후에도 활동 패턴 다르면 정지
- **결론: 네이버는 1 계정만 운영. 다중 계정 비추.**

## 8. 빙 Webmaster Tools 등록

각 own 도메인마다:

1. https://www.bing.com/webmasters 로그인
2. Add a site → `https://{domain}` 입력
3. DNS TXT 레코드로 인증 (또는 메타태그)
4. Sitemap 제출: `https://{domain}/sitemap_index.xml`

### 체크리스트

- [ ] own 도메인 1 등록

- [ ] 모든 도메인 sitemap 제출
