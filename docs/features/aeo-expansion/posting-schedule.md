# 발행 일정표

## 핵심 원칙

1. **점진적 게시** — 한 번에 도배 X. 운영자가 여러 명인 자연스러운 패턴.
2. **시간대 분산** — 채널별 다른 시간대 (아침/점심/저녁/심야)
3. **요일 분산** — 모든 채널이 매일 게시 ❌
4. **간격 일정** — 같은 채널은 24-72시간 간격 유지

## 이상 감지 시 대응

### "글 게시 후 30일 인덱싱 안 됨"
- robots.txt 확인 (`Sitemap: https://...`)
- canonical 확인 (https + trailing slash)
- 외부 백링크 0개라면 → 티스토리/네이버에서 자연 언급 추가

### "도메인 1개 deindex"
- footprint 점검 (다른 도메인과 같은 IP/페르소나 흔적 있는지)
- 콘텐츠 감사 (다른 도메인과 본문 일치 검사)
- 해당 도메인은 회복 시간 길음 → 새 도메인으로 대체

### "ChatGPT 인용 안 됨 (4주 후에도)"
- 콘텐츠 깊이 부족 → 1500자 → 2500자로 확장
- 권위 출처 인용 추가 (미슐랭, 다이닝코드 별점)
- 외부 백링크 강화 (인스타/카페 자연 신호)
