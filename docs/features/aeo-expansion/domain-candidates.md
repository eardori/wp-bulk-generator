## 최종 추천 조합 (own 도메인 2개 신규)

### 옵션 A: niche 강화 (갈비 컨센서스 ↑)
```
chowlog.xyz                   ← 현재 (재민)
hanwoo-master.com             ← 신규 1 (김셰프)
```

**장점**: 모두 미식/한우 niche. 컨센서스 효과 강함.

**장점**: 매거진 1개 보유로 향후 병원/학원 추가 시 모두 커버.
**예상 비용 (1년)**: $25-30

**장점**: 갈비 권위 최강.
**단점**: 다른 영업처 확장 시 도메인 추가 필요.

## 도메인 구매 절차 (Porkbun 기준)

1. https://porkbun.com 가입
2. 도메인 검색 → 장바구니 추가
3. WHOIS Privacy 체크 (무료, 자동 적용)
4. Auto-renew 체크 (실수로 도메인 잃지 않도록)
5. 결제 (해외 카드 OK)
6. 등록 후 5-10분 내 활성화

→ DNS 설정은 Phase 2에서 (호스팅 결정 후).
